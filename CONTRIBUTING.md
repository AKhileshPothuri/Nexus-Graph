# Contributing to Nexus-Graph

Thank you for your interest in contributing to Nexus-Graph! We welcome contributions of all kinds, including bug reports, feature requests, documentation improvements, and code changes.

## How to Contribute

1. **Fork the repository** and create your branch from `main`.
2. **Open an issue** to discuss your proposed change before submitting a pull request.
3. **Write clear, concise commit messages** and follow the existing code style.
4. **Add tests** for new features or bug fixes when possible.
5. **Submit a pull request** with a clear description of your changes.

## Code of Conduct

Please be respectful and inclusive. By participating, you agree to abide by our [Code of Conduct](CODE_OF_CONDUCT.md).

## Reporting Issues

- Use [GitHub Issues](https://github.com/AKhileshPothuri/Nexus-Graph/issues) to report bugs or request features.
- Provide as much detail as possible, including steps to reproduce and relevant logs or screenshots.

## Getting Help

If you have questions, open an issue or start a discussion in the repository.
